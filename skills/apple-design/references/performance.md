# 光学性能与生命周期

仅在性能或资源管理问题出现时读取。参数是起点，不能据此承诺帧率。

- 渲染区域、像素数、采样次数和纹理上传共同影响成本。全屏尤其限制 DPR；默认上限 1.5，可按实测下降，不能用面积公式推断毫秒值。
- 同一场景按功能组共享表面；本引擎容量见 Web API，不靠不断增加上下文规避预算。
- 静止时不重复上传纹理或循环 rAF；视频按实际新帧更新。布局变化时批量测量，动画用缓存几何与 transform/opacity。
- 收敛或页面隐藏时停调度；卸载清理观察器、事件、计时器、指针状态与 renderer。返回缓存页面时按生命周期恢复。
- 上下文丢失显示真实降级，恢复后重新上传来源；来源/尺寸恢复正确后再调性能。
- 优先降低分辨率和无必要的绘制面积；最终关闭光学时标明基础降级。
- 记录实际浏览器、设备、DPR、视口和来源类型，比较开启/关闭及交互期间的录制。静态截图不证明帧率，桌面测试不证明低端手机表现。
