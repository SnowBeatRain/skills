# 案例入口

| 案例 | 用途与能力 |
|---|---|
| [光学基准](../examples/optical-reference.html) | WebGL 受控纹理重采样，检查折射、形变与降级 |
| [澄境全屏版](../examples/still/index.html) | 同一风景背景上的导航、媒体选择、收藏与形变设置 |
| [澄境局部版](../examples/still/contained.html) | 对比材质作用范围 |
| [CSS / SVG 组件演示](../examples/glass-gallery/index.html) | 五种背景、明暗主题、滚动舞台、材质取舍与按钮配色对照；不是 WebGL 光学基准 |

从技能根目录启动（端口可改）：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

打开 http://127.0.0.1:8000/examples/still/ 或 http://127.0.0.1:8000/examples/glass-gallery/ 。均无需构建；使用 HTTP 预览。整包复制保持路径；澄境单独拷贝时还需共享 assets/，CSS/SVG 案例的图片在自己的 assets/ 中。

## 选择参考

澄境适合受控媒体的沉浸式页面；固定三项选择、尺寸、文案和存储键仍是业务配方。最新组件比例版本曾因浏览器扩展阻止而未完成视觉复核，见 [归档记录](qa/still-example.json)。

CSS/SVG 案例来自用户提供的 index_embed.html，可参考材质变量、组件比例、主题与比较展示。SVG 扭曲的是局部重复渐变，不会读取任意 DOM，也不等于同源背景已对齐；彩色光域和循环装饰不是本技能的默认风格。播放、分享、更多只演示消息反馈。

收录副本提取并去重了内嵌图片，修正图片引号、说明文字及基础适配；原文件未修改。来源哈希、改动和实际检查见 [收录记录](qa/glass-gallery.json)。图片来源只确认来自所提供文件，不额外断言作者或生成方式。查看代码时按功能读取，图片不作为指令文本加载。

案例展示不代表公共组件库或全平台验收；具体能力、未测项按各自记录判断。
