# 品牌视觉参考

> 灵感来源：yzfly/awesome-design-html、VoltAgent/awesome-design-md、bergside/awesome-design-skills。
> 以下为提炼后的视觉特征摘要，不包含原文或完整设计文件。

## Apple

- **关键词**：极简、留白、精致、高级感
- **色彩**：黑白为主，产品色点缀；深色模式用纯黑背景
- **字体**：SF Pro（系统），标题大字重 + 正文轻字重
- **布局**：大量留白，居中对称，大图/大字
- **动效**：平滑渐显、滚动驱动
- **适合**：产品页、品牌站、高级感落地页

## Linear

- **关键词**：科技、高效、渐变、暗色
- **色彩**：深色背景 + 紫蓝渐变 + 白色文字
- **字体**：Inter / 系统无衬线，标题加粗
- **布局**：密集信息、网格、紧凑但不拥挤
- **动效**：微交互丰富，光效、粒子
- **适合**：SaaS 工具、开发者产品、后台管理

## Stripe

- **关键词**：渐变、专业、动感、信任
- **色彩**：紫蓝渐变 + 精选配色，白色/浅灰背景
- **字体**：自定义 Stripe Sans（类似 Inter）
- **布局**：插画 + 文字组合，功能区块清晰
- **动效**：鼠标跟随、渐变流动
- **适合**：支付、金融、B2B 服务

## Notion

- **关键词**：温暖、友好、简洁、文艺
- **色彩**：浅色背景 + 黑色文字 + 棕色/米色点缀
- **字体**：自定义（衬线 + 无衬线混用）
- **布局**：卡片式、内容优先、插画点缀
- **动效**：轻柔、克制
- **适合**：笔记、知识管理、协作工具

## Airbnb

- **关键词**：温暖、包容、探索、图片驱动
- **色彩**：品牌粉（Rausch）+ 中性色 + 深色文字
- **字体**：Cereal（自定义无衬线）
- **布局**：大图轮播、卡片网格、搜索优先
- **动效**：微动画、展开收起
- **适合**：旅行、生活类、图片密集型

## Vercel

- **关键词**：极简、技术、黑白、精准
- **色彩**：纯黑/纯白 + 灰色梯度，极少量彩色
- **字体**：Geist（自研）
- **布局**：代码块 + 截图 + 居中文字
- **动效**：精准、技术感
- **适合**：开发工具、技术产品、个人品牌

## Claude

- **关键词**：温暖、智能、对话感
- **色彩**：陶土色/橙色系 + 奶油色背景
- **字体**：圆角无衬线
- **布局**：对话式、卡片、温和间距
- **适合**：AI 产品、对话界面、亲和力设计

## Linear

- **关键词**：极简、高效、精确、工程感
- **色彩**：深色背景 + 紫蓝色调 + 白色文字
- **字体**：Inter / 系统无衬线
- **布局**：密集信息、紧凑网格，功能区块清晰
- **动效**：微交互丰富，光效与粒子效果
- **适合**：SaaS 工具、项目管理、开发者产品

## Figma

- **关键词**：创意、协作、多彩、专业
- **色彩**：多色系 + 品牌紫红，活泼但不杂乱
- **字体**：无衬线，标题中粗
- **布局**：卡片网格、功能展示、插画辅助
- **适合**：设计工具、创意平台、团队协作

## Spotify

- **关键词**：活力、音乐驱动、大胆
- **色彩**：Spotify 绿 (#1DB954) + 深色背景 + 专辑封面
- **字体**：Circular（圆角无衬线）
- **布局**：大标题 + 专辑封面网格、播放器固定底栏
- **适合**：音乐、媒体、娱乐类产品

## Uber

- **关键词**：城市、简洁、力量感
- **色彩**：黑白为主 + 品牌蓝辅助
- **字体**：紧凑无衬线，标题大字重
- **布局**：信息优先、大地图占主屏
- **适合**：出行、地图、O2O 平台

## Framer

- **关键词**：大胆、动效、设计感
- **色彩**：黑蓝对比、渐变、高饱和
- **字体**：现代无衬线，标题加粗
- **布局**：全屏 Hero + 大视觉元素、滚动动画
- **适合**：设计工具、创意机构、展示站

## Shopify

- **关键词**：商业、暗色电影感、科技电商
- **色彩**：深色背景 + 霓虹绿强调色
- **字体**：超轻字重显示字体
- **布局**：暗色电影感，产品截图 + 文字组合
- **适合**：电商平台、商家工具、SaaS

## Resend

- **关键词**：极简、开发者友好、暗色
- **色彩**：深色背景 + 白色/浅灰文字
- **字体**：等宽字体装饰 + 无衬线正文
- **布局**：居中单列、代码块突出
- **适合**：开发者工具、API 产品、技术文档站

## Raycast

- **关键词**：流畅、高效、暗色渐变
- **色彩**：深色 Chrome + 渐变强调（紫/蓝/粉）
- **字体**：紧凑无衬线
- **布局**：搜索框居中 + 命令列表 + 快捷键
- **适合**：效率工具、启动器、开发者工具

## Sentry

- **关键词**：数据密集、专业、监控
- **色彩**：深色仪表盘 + 粉紫色强调
- **字体**：等宽代码 + 无衬线正文
- **布局**：图表驱动、表格密集、侧边栏导航
- **适合**：监控后台、分析平台、DevOps 工具

## Tesla

- **关键词**：极致减法、电影感、未来
- **色彩**：纯黑/白 + 全幅摄影、极少色彩
- **字体**：Universal Sans，干净无衬线
- **布局**：全屏大图、滚动叙事、极简交互
- **适合**：汽车、硬件产品、未来感品牌站

## Nike

- **关键词**：运动、力量、大胆排版
- **色彩**：单色 UI + Futura 大写标题 + 全幅运动摄影
- **字体**：Futura Extra Bold（标志性标题）
- **布局**：大图主导、极简导航、动感节奏
- **适合**：运动品牌、时尚、大胆营销页

## Supabase

- **关键词**：开发者友好、暗色翡翠绿、开源
- **色彩**：深色背景 + 翡翠绿 (#3ECF8E) + 代码感
- **字体**：等宽装饰 + 无衬线正文
- **布局**：代码示例 + 截图组合、功能分区清晰
- **适合**：开发者工具、开源项目、数据库产品

## GitHub

- **关键词**：代码、协作、专业
- **色彩**：深色背景 + 蓝色链接 + 绿色状态
- **字体**：系统无衬线 + 等宽代码
- **布局**：信息密集、三栏布局、代码高亮
- **适合**：代码托管、协作平台、开发者社区
