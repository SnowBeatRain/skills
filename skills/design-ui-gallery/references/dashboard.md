# Dashboard 风格

## 常见布局

```
┌──────────┬────────────────────────────┐
│          │  Header (搜索 + 通知 + 头像) │
│  Sidebar │────────────────────────────│
│  (导航)   │                            │
│          │  Main Content              │
│          │  (数据卡片 / 表格 / 图表)     │
│          │                            │
└──────────┴────────────────────────────┘
```

## 风格选择

| 场景 | 推荐风格 | 说明 |
|------|----------|------|
| 数据分析 | 极简 + 暗色 | 图表突出，减少干扰 |
| 项目管理 | 扁平化 2.0 | 信息密集但有序 |
| 创意工具 | 暗色 + Glassmorphism | 专业感、现代感 |
| 运营后台 | 极简 + 浅色 | 功能优先、操作效率 |

## 关键组件

- **数据卡片**：指标名 + 数值 + 趋势图 + 环比/同比
- **表格**：排序、筛选、分页、行操作
- **图表**：折线图（趋势）、柱状图（对比）、饼图（占比）
- **侧边栏**：可折叠、图标 + 文字、当前项高亮

## 信息密度

| 类型 | 密度 | 说明 |
|------|------|------|
| 紧凑 | 行高 32px | 数据密集型 |
| 默认 | 行高 40px | 通用型 |
| 宽松 | 行高 48px | 展示型 |
