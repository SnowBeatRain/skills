# Liquid Glass 视觉原理

本文件定义跨平台近似配方，Apple 原生材质优先遵循系统行为。不要将 Web 的 blur 数值、透明度、阴影或预算描述为 Apple 官方规范。

## 1. 五个视觉线索

| 线索 | 用途 | Web 实现 |
|---|---|---|
| 背景模糊 | 暗示背后仍有内容 | backdrop-filter 的 blur |
| 饱和提升 | 减少模糊后的灰浊感 | 同一声明中配 saturate |
| 边缘高光 | 提示材质边界 | 1px 半透明白边、顶部 inset |
| 柔和投影 | 将浮层从背景抬起 | 大半径、低透明度单个外阴影 |
| 动态响应 | 给指针/触摸适量反馈 | 径向高光、一次性扫光 |

页面背景是前提，不算组件的一层。背景 → 玻璃主体 → 装饰 → 文字/图标；文字与图标不模糊、不能依靠整体 opacity 降低层级。装饰层不能截获事件。

## 2. 层次与强度

优先导航、工具栏、浮动控件与临时面板；长篇正文保留实底。不要因要求“Apple 风格”就把每个卡片或列表项变成玻璃。

默认视觉方向是简约、素净：浅色用纸白、浅灰、柔和灰阶阴影，深色用炭灰、石墨灰和克制高光。利用背景内容与明暗差建立层次，不主动加入高饱和红紫蓝底色、多色光球、彩虹徽标或循环渐变。已有品牌色仅用于必要操作和状态，不能把品牌强调色铺满页面。

| 层级 | 配方 | 取舍 |
|---|---|---|
| 页面背景/壁纸 | 低饱和、有明暗变化 | 不用纯色演示透光 |
| 大面积容器/侧栏 | subtle：12px / 140% / α .08 | 限制面积与合成成本 |
| 卡片/浮动导航/弹窗 | medium：24px / 180% / α .14 | 默认平衡 |
| 小按钮/TabBar | strong：36px / 220% / α .22 | 边框 α .50，面积应小 |
| 内容 | 不透明文字/图标 | 对比度优先 |

这三档是视觉强度配方：strong 的 blur 与填充 α 都更高。不要同时规定“越靠近用户模糊越低、透明度越高”，那与此表矛盾。景深主要通过位置、面积、边界与阴影表达。同屏通常最多两档；嵌套目标 1 层，绝不超过 3 层。

## 3. 圆角

优先 24px / 32px 连贯圆角；最小 16px。44px、pill 用于大形状/药丸。只有明确贴边的导航允许 0px。所有圆角来自 `../assets/tokens.json`。

```css
.lg-radius--lg { --lg-radius: var(--lg-radius-lg); }
```

```swift
RoundedRectangle(cornerRadius: 24, style: .continuous)
```

Web border-radius 不是严格的 squircle。不要把 `clip-path: path('...')` 占位符交给用户；自定义路径会裁切后代且不一定自适应。`glassEffect` 的默认 shape 由系统定义，不等于默认 24px 连续矩形，需要时显式传 shape。

## 4. 高光

- 固定顶部 inset：浅色 α .75、深色 α .28；底部 α .12。
- 动态径向光：浅色 α .38、深色 α .20；参考半径 320px，显示 opacity .6。极小/极大组件可在 Token 中适配。
- 扫光：浅色 α .28、深色 α .14，115°，900ms，仅一次，不无限循环。
- CSS 资源用受圆角约束的固定渐变淡入淡出近似掠光；没有光斑穿越组件的真实折射。若需要移动光带，添加独立裁切装饰层，不让超大伪元素伸出边缘。
- 高光强度低于文字层的重要性；关闭动态时保留顶部静态 inset 即可。

## 5. 可读性与主题

填充 α .14 本身不能保证文字可读。资源在玻璃底色上叠加独立的 readable 遮罩：浅色白 α .56 + 深色文字，深色中性炭灰 α .80 + 浅色文字；这会牺牲部分通透度。实际总透明度不等于 intensity.backgroundAlpha。

背景已受控且采样证明达标时，可调整 readable Token，不能直接移除遮罩后声称对比度不变。正文 ≥4.5:1，大号文字 ≥3:1。优先加强局部底色/遮罩、调整文字颜色，最后才考虑轻微文字投影，禁止只靠文字投影过关。

深色背景 α .06、边框 α .18、外阴影 α .50，降低高光强度。不要为“更暗”无节制叠加灰色填充；可读性不足时仍允许增加遮罩。深色规则应覆盖组件强度类，而非只改 :root。

## 6. 错误对照

| 错误 | 后果 | 修正 |
|---|---|---|
| 只 blur，不 saturate | 灰浊 | 成对使用 |
| filter: blur | 文字一起模糊 | backdrop-filter |
| 纯白实线 + 硬黑短投影 | 边界僵硬 | 半透明亮边 + 软投影 |
| 8px 浮动卡片圆角 | 不符合此配方 | ≥16px，优先 24/32px |
| 为厚度堆五层以上阴影 | 浑浊、过量装饰 | 顶部/底部 inset + 一个外阴影 |
| 玻璃套玻璃、列表逐项玻璃 | 合成开销、透光不稳定 | 单层容器或实底内容 |
| 纯色背景、随机外链照片 | 无视觉依据或效果不可复现 | 受控本地渐变/素材 |
| 降级变浅底但保留白字 | 无法阅读 | 同步语义文字 Token |

## 7. 官方依据与边界

- [Apple Liquid Glass 概览](https://developer.apple.com/documentation/technologyoverviews/liquid-glass)
- [Apple HIG Materials](https://developer.apple.com/design/human-interface-guidelines/materials)
- API 与最低 SDK 以 [SwiftUI / UIKit 指南](swiftui-implementation.md) 中的官方链接为准。

Web 本配方无法复刻系统边缘折射、背景色调自适应或玻璃融合。SVG/WebGL 自绘涉及独立采样与渲染管线，并非给任意 DOM 加一个滤镜就能通用复现；未要求时不引入。
