## 1. 设计原则

Apple 现行官方原则共 8 项（2026 年更新）：**目标感、能动性、责任感、熟悉感、灵活、简洁、匠心、愉悦感**。核心主张：最成功且经久不衰的设计基于对"用户如何思考、感受和与世界交互"的深刻理解；原则是权衡冲突时的决策工具，不是教条。

传统三原则（早期 iOS 表述，仍具指导性）：**清晰 Clarity**（各尺寸文字易读、图标精确、功能驱动）、**遵从 Deference**（UI 帮助理解内容而非与之竞争）、**深度 Depth**（视觉层次与真实动效传达层级）。

### 2.2 语义化使用规则

- 颜色必须**表达语义**（成功/错误/主操作/警示），不做装饰。
- 主操作色 + 状态色（成功绿/错误红/警示橙）每屏尽量唯一。
- 文字层级：主文字 ≈ `#1D1D1F`（浅色）/`#F5F5F7`（深色），次要 `#86868B`（浅）/`#AEAEB2`（深），禁用文字用系统灰。
- 背景：浅色 `#FFFFFF`/分组 `#F2F2F7`；深色 `#000000`/分组 `#1C1C1E`。
- 对比度：正文 ≥ 4.5:1，大字 ≥ 3:1（WCAG AA）。
- **不要只用颜色传达状态**，配合文字/图标/形状。

## 3. 字体排印

- **西文**：SF Pro（iOS/macOS 默认）、SF Pro Rounded、SF Mono（代码）；衬线用 New York。
- **中文**：苹方 PingFang SC（简体）、PingFang TC/HK（繁体）、Songti SC（衬线）。
- **网页字体栈**：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Helvetica Neue", "Microsoft YaHei", sans-serif`。
- **动态字号**：正文支持 Dynamic Type（iOS 1–4 倍缩放），网页提供字号缩放入口。
- **字阶建议**（网页/界面通用）：

| 角色 | 大小/字重 | 说明 |
|---|---|---|
| 大标题 | 28–34px / 700 | 每页 ≤1 个 |
| 标题 | 20–24px / 600–700 | 区块标题 |
| 正文 | 15–17px / 400 | 主内容 |
| 说明 | 13–14px / 400 | 次要信息 |
| 小字/标签 | 11–13px / 400–500 | 时间戳、标签 |

- 行高：正文 1.4–1.6；标题 1.2–1.3；行宽建议 45–75 字符。

## 4. 间距与布局

- **8pt 栅格**：间距取 4/8/12/16/20/24/32/40/48/64。
- 屏幕边距：iOS ≈16pt，macOS ≈20pt，网页桌面 ≥16px、移动端 16px。
- 卡片/列表内边距：12–16px；卡片间距 8–12px。
- 安全区：适配状态栏、灵动岛、圆角、底部 Home 条（至少 34px）。
- 布局原则：**内容优先**，重要内容放在拇指热区（移动端下半屏）或视口左上方（网页 F 型阅读）。

## 5. 材质与层级

- **材质**：系统毛玻璃（Ultra Thin/Thin/Regular/Thick）+ 半透明颜色，用于浮层、侧栏、工具栏，传达"当前层级"。
- **Liquid Glass**（WWDC25 全新设计语言）：玻璃质感、高光、半透明分层；网页可用 `backdrop-filter: blur(20px) saturate(1.5)` + `rgba(255,255,255,0.6)`（深色用 `rgba(28,28,30,0.6)`）。
- **层级手段**：内容层（实底）→ 导航层（毛玻璃）→ 浮层（毛玻璃+阴影）。不要用过度阴影；阴影柔和：`0 1px 3px rgba(0,0,0,.08), 0 4px 12px rgba(0,0,0,.06)`。
- 圆角：卡片 10–16px、按钮 10–12px、输入框 10px、胶囊/标签 999px（Apple 未公布统一圆角规范，此为业界常用近似值，可按设计尺度统一）。

## 6. 图标

- 语义化优先：图标必须一眼可懂，配合文字标签。
- 风格：线性/填充统一、几何规范、边角圆润（SF Symbols 风格 1.5–2px 描边）。
- iOS 用 SF Symbols（7,000+ 符号）；网页用同风格线性图标（如 Lucide/自绘 SVG）。
- 图标尺寸：界面 16/20/24/28px；触控目标 ≥44×44pt（含内边距）。

## 7. 常用组件

| 组件 | 规范 |
|---|---|
| 导航栏 | 毛玻璃底、标题居中或左对齐、操作按钮靠右；返回始终可到上级 |
| 标签栏/侧栏 | 3–5 个主分区；当前项高亮（色+状态）；侧栏支持折叠 |
| 卡片 | 白底/毛玻璃、圆角 12–16px、轻阴影；关键信息置顶 |
| 按钮 | 主按钮系统蓝实底白字；次按钮透明底蓝字；破坏性红色；圆角 10–12px；按压有状态变化 |
| 输入框 | 圆角 10px、灰底 `#F2F2F7`（浅色）、placeholder 用次要灰；聚焦时边框/底色变化 |
| 列表 | 分组列表圆角卡片式；行高 ≥44pt；分隔线 1px `rgba(60,60,67,.29)`（iOS 标准分隔色） |
| 弹窗 | 居中、圆角 14px、标题+正文+2 个按钮（默认+取消）；背景遮罩半透明 |
| 开关/单选 | 开关绿/蓝；状态明确；禁用态降低对比度 |
| 搜索栏 | 圆角输入框+放大镜图标+占位文字；支持清空/语音 |
| 空状态 | 图标+一句说明+一个行动按钮；不能空白 |

## 8. 动效

- 自然物理：快慢符合直觉（进入快、退出稍慢），曲线用 ease-out/ease-in-out。
- 时长：微交互 150–200ms，页面转场 250–350ms。
- 用途：表达层级（进入/离开）、状态变化（选中/成功）、引导注意（警示）。
- **克制**：不为动而动；支持 `prefers-reduced-motion` 关闭。

## 9. 无障碍

- 动态字号/字体缩放；布局随字号自适应不截断。
- 颜色对比度达标（见 §2.2）；不依赖颜色传达信息。
- 语义化：网页用语义标签+ARIA；iOS 配置辅助功能标识（VoiceOver 可读）。
- 触控目标 ≥44×44pt；支持键盘导航（网页 Tab 顺序、macOS 快捷键）。
- 深色模式完整适配。
