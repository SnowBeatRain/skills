# 验收：按改动取证

这是唯一验收清单入口。静态检查、实际交互、视觉与目标平台结果分开报告；过去的通过只属于记录对应的版本和环境。

## 1. 选择检查范围

| 改动 | 检查 |
|---|---|
| 普通样式/组件比例 | 目标视口、长标签、真实数量范围、命中区、主题、缩放与键盘；不要求 WebGL A/B |
| 已有光学场景的布局 | 上述项目，加改变区域的玻璃边界、背景对齐和合成对比度 |
| 局部扩展到全屏 | 角落与边界覆盖、裁切、窗口变化、浮层避让及新区域光学表现 |
| 渲染器/来源/材质变化 | 相关光学对照、透光、动效、输入与降级 |
| 公共组件提取 | 原调用点、多实例隔离、动态内容、生命周期、焦点及工程检查 |

首次接入可运行包内光学基准，已有项目从当前实现检查。代码存在或 WebGL 创建成功不等于画面正确。普通 UI 的可读性/输入细节仅在需要时查 [accessibility.md](accessibility.md)。

## 2. 光学用例

| id | 通过条件 |
|---|---|
| lensing | 同条件开/关对照中边缘纹理确有位移；只变亮度不算 |
| transmission | Web 透明透镜仍能辨认来源，没有被全区域遮罩抹掉 |
| morph | 产品中相关形变保持几何连续；采集中间状态，不只看终点 |
| input | 适用的键盘、鼠标/触摸、取消、关闭和回焦有效 |
| fallback | 能力不足或实底模式下状态准确且操作仍可用 |
| motion | 减少动态立即收敛，无残留循环/弹性；可以保留静态折射 |
| contrast | 普通文字 ≥4.5:1，大字 ≥3:1；针对合成背景采样或给出范围明确的估算 |

这些是本包 Web 光学基准的用例，不要求普通页面新增拖动/菜单来凑数，也不强迫原生 Regular、大侧栏或辅助功能外观透明。

A/B 保持来源、裁切、位置、viewport、DPR、缩放、字体、加载状态和布局矩形一致，暂停运动并移开指针。若字体或排版也变了，不能把全图像素差归为折射；未排除混杂因素时不标通过。

## 3. 记录与工具

从技能根目录执行（其他入口替换最后的文件路径）：

```sh
node scripts/validate.mjs --profile optical examples/optical-reference.html
node scripts/validate.mjs --manifest manifest.json examples/optical-reference.html
node scripts/validate.mjs --profile optical --evidence references/qa/optical.json examples/optical-reference.html
```

第一条仅预检；第二条只生成来源哈希；第三条核对已有记录完整性，不理解截图。完整收据采用以下结构，entry/files 从当前 manifest 获取：

```json
{
  "version": 1,
  "profile": "optical",
  "renderer": "webgl",
  "entry": "examples/optical-reference.html",
  "files": {},
  "testedAt": "填写实际检查时间",
  "environment": {"browser": "实际浏览器", "width": 1280, "height": 960},
  "cases": [
    {"id": "lensing", "status": "not-run", "notes": "待实际检查", "evidence": []}
  ]
}
```

完整 --evidence 收据需覆盖上表七项，实际完成后才能填 pass；截图须为记录目录内的相对 PNG，代码哈希须匹配。示意记录不能通过。远程媒体不在本地依赖图内，另记录固定版本/哈希与采样条件。

局部修改可以用单独的增量报告：写明 scope、当前文件哈希、环境、已测及未测项，不为凑七个 pass 重测无关功能。增量报告不传给 --evidence，也不代表完整光学验收。只读建议无需创建验收文件。

## 4. 受阻与交付

浏览器自动化/扩展/截图阻止检查，记为验证受阻；只有页面能力检测或真实运行错误才证明 GPU/滤镜不可用。完成可独立执行的已授权检查，交付当前入口和具体未测项，不重新审批实施、不机械重试或绕过限制。

测试改变了主题、折射、弹层或临时视口时，交付前在可控范围恢复约定状态并读回，再释放预览资源。调用失败不能宣称“已恢复”；说明实际状态及可用的刷新方式。

打包/迁移时检查独立目录中的资源闭合与运行；不要带入宿主绝对路径、会话状态。框架、浏览器和真机验证按目标范围补做，不把应用内偏好模拟等同系统测试。
