# 普通 Apple 风格网页

用于普通网页与标准毛玻璃。沿用已有框架、组件和品牌，不因使用本技能改成单文件 HTML 或全屏照片。

## 实现重点

1. 按产品组织内容：阅读/营销页可用留白与窄栏，后台/编辑器按数据密度使用空间；不强塞 Hero 或统一最大宽度。
2. 保持导航、按钮、表单的主次与一致状态。普通内容使用可读背景；导航是否吸顶、实底或毛玻璃由任务决定。
3. 接入真实链接、事件、空状态和错误恢复；弹层处理关闭及焦点。静态骨架不是完整交互。
4. 长标签与窄屏先调整排布、换行、滚动或折叠，不删除必要入口或统一缩小字体。固定/悬浮控件为内容预留空间。
5. 保留浏览器缩放和键盘操作；Web 常用触摸目标约 44 CSS px。主题与降级切换要同时调整背景、文字、边界和焦点。

## 使用现有资产

[apple-web-template.css](../assets/apple-web-template.css) 提供主题变量、基础组件和标准毛玻璃。按需并入项目样式；不要复制文档中的另一份颜色表，也不要覆盖已有组件库的行为。

使用模板时处理其具体边界：
- 窄屏隐藏导航的 CSS 不包含菜单逻辑，须补齐等效入口或覆盖该规则。
- 仅可交互卡片使用 hover 位移；静态内容不暗示可点击。
- 网格最小列宽不得超过容器；例如 minmax(min(100%, 280px), 1fr) 的 280px 仍需按内容调整。
- 原有 px 配方不替代字号缩放和内容自适应。
- 模板提供无滤镜、减少透明度/增强对比度、强制颜色处理；html 上的 data-reduced-transparency="true" 是可选实底入口。目标浏览器是否映射系统偏好仍需验证。

任务只涉及组件比例时追加 [尺寸规则](component-patterns.md#1-尺寸与排布)；需建立色彩/字体体系时追加 [设计基础](design-system.md)。仅当目标明确为 Web Liquid Glass 时转到 [光学接入](web-implementation.md)，不要把 backdrop-filter 标为真实折射。

按本次改动检查布局、长标签、主题、键盘、缩放和实际降级；无光学目标不要求折射 A/B。
