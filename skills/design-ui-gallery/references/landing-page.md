# 落地页风格

## 常见结构

```
Hero（首屏）
  ├── 主标题 + 副标题 + CTA
  └── 配图 / 动画 / 产品截图

Social Proof（信任背书）
  └── Logo 墙 / 数据指标 / 客户评价

Features（功能展示）
  └── Bento Grid / 左图右文 / Tab 切换

How it Works（使用流程）
  └── 步骤卡片 / 时间线

Pricing（定价）
  └── 三栏对比 / Toggle 月付/年付

CTA（行动号召）
  └── 大按钮 + 简短文案

Footer
```

## 风格选择

| 产品类型 | 推荐风格 | 参考 |
|----------|----------|------|
| SaaS 工具 | 极简 + 暗色 | Linear、Vercel |
| 消费产品 | 温暖友好 | Airbnb、Notion |
| 创意机构 | 粗野主义 / 大胆 | Kerrigan、MSCHF |
| 技术产品 | Glassmorphism / 暗色 | Stripe、Raycast |
| 教育/儿童 | Claymorphism | Duolingo 风格 |

## 关键指标

- 首屏加载 < 2s。
- 主 CTA 首屏可见。
- 移动端适配完整。
- 文案简洁（标题 < 10 字，副标题 < 30 字）。
