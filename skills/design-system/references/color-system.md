# 配色系统与深色模式

## 配色方法

### 从品牌色出发

1. 取品牌主色 HSL 值。
2. 调节明度（Lightness）生成色阶：50 / 100 / 200 / 300 / 400 / 500 / 600 / 700 / 800 / 900。
3. 500 用于交互元素（按钮、链接），600-700 用于悬停态，100-200 用于浅色背景。

### 语义色

| 用途 | 色相建议 | 说明 |
|------|----------|------|
| Success | 绿色系 (H: 120-160) | 传达成功、完成、确认 |
| Warning | 琥珀系 (H: 30-50) | 传达警告、需注意 |
| Error | 红色系 (H: 0-15) | 传达错误、危险、删除 |
| Info | 蓝色系 (H: 200-230) | 传达提示、信息 |

### 中性色

用纯灰色或微带品牌色的灰色（冷灰 / 暖灰）。常见做法：

```css
/* 冷灰 */
--gray-50: #f8fafc;
--gray-900: #0f172a;

/* 暖灰 */
--gray-50: #fafaf9;
--gray-900: #1c1917;
```

## 深色模式

### 原则

- 不是简单反转，而是降低对比度、调整色温。
- 深色背景不要用纯黑（#000），推荐 #111 / #1a1a / #0f172a。
- 文字不要用纯白（#fff），推荐 #e5e5e5 / #f1f5f9。
- 彩色在深色模式下需要降饱和度、提亮度。

### 实现

```css
:root {
  --bg-primary: #ffffff;
  --text-primary: #1a1a1a;
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg-primary: #111111;
    --text-primary: #e5e5e5;
  }
}

/* 或用 class 切换 */
.dark {
  --bg-primary: #111111;
  --text-primary: #e5e5e5;
}
```

## 对比度

- 正文文字对比度 ≥ 4.5:1（WCAG AA）。
- 大标题/图标 ≥ 3:1。
- 工具推荐：Chrome DevTools 的颜色对比度检查器。
