# 材质上的可读性与输入

用于辅助功能实现或专项检查；通用设计规则不在这里重复。

## 合成对比度

普通文字 ≥4.5:1，大字 ≥3:1（Web ≥24px 常规或 ≥18.66px 粗体）。对最终合成背景测量，覆盖边缘、高光和改变后的状态，不只比较不透明 Token。

本基准的局部白色 α .56 衬底配 #1D1D1F，在简化极端黑底的 sRGB 合成下约 5.19:1；仅约束该配方，不是任意图片/主题的认证。亮度计算先将 sRGB 线性化，L=.2126R+.7152G+.0722B，对比=(较亮L+.05)/(较暗L+.05)。

原生使用语义前景和 vibrancy；Web 无系统等价保证。增加局部衬底后仍需复核；复杂内容优先阅读，不以透光为目标强行使用透明材质。

## 输入语义

- 画布 aria-hidden，真实 button/a/input/nav 保留在 DOM；Canvas 文字不承担唯一语义。
- 图标名称、选中/禁用/展开状态完整，焦点可见且不被裁切；状态不只靠颜色。
- Web 常用命中区约 44 CSS px，图标可更小；200% 缩放和窄屏不丢内容。具体平台遵循其规范。
- 拖动提供键盘/等效操作，正确处理 pointer capture 的 up/cancel/lostcapture。
- Disclosure 配 aria-expanded/aria-controls；关闭内容用 hidden/inert，不能只设 opacity:0。Escape 关闭并合理回焦；模态使用对应焦点约束。

## 系统偏好

- CSS 的 prefers-reduced-motion 不会停止 JS/WebGL；监听变化，停止/收敛 rAF并直接应用目标几何。
- 降低透明度、增强对比度和 forced-colors 是不同条件。Web 可隐藏光学输出并显示实底，切换时成对更新前景与背景。
- 媒体查询支持及系统映射按目标浏览器实测，未命中不证明没有需求；可提供应用级实底/减少动态入口，不能以该入口测试冒充真机系统验证。
- forced-colors 使用 Canvas、CanvasText、Highlight 等系统色，去掉阴影装饰，不用 forced-color-adjust:none 阻止用户配色。
- 原生系统材质自行适应辅助功能；其更磨砂外观不等于 Web 的实底兼容策略。自定义布局、颜色和动效仍需验证。
