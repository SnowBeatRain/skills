# 组件尺寸与复用

尺寸精修读第 1 节；公共组件任务读第 2 节。先沿用当前组件库与 Tokens，规则中的数值不作为统一 HIG 标准。

## 1. 尺寸与排布

| 对象 | 默认宽度策略 | 需要调整的情况 |
|---|---|---|
| 图标按钮 | 稳定方形占位；图标与命中区分开 | 16–24px 图标可配约 44px Web 热区；不能覆盖相邻操作 |
| 文字按钮 | 内容加内边距，同组高度一致 | 表单主操作可伸展；长标签允许换行并增加高度 |
| 分段选择 | 短而等价的标签可等宽，否则按内容分配 | 项目增多或文字变长时调整排列/滚动/选择方式，不压缩到难读 |
| 浮动导航/工具栏 | 按分组收紧并限制最大宽度 | 工作栏、搜索等需要利用可用空间时可以全宽 |
| 媒体选择区 | 有界伸展，保证内容可辨认 | 按图片比例、列数、间距和标签推导宽度，不固定三列 |
| 设置/表单面板 | 有界阅读宽度，输入控件填充其所在区域 | 受视口、安全区和键盘约束；高度不足内部滚动，保留关闭入口 |

max-content/fit-content 仍需处理容器上限、flex/grid 最小宽度、长字符串和缩放。“全屏”决定场景范围，不决定以上尺寸。历史 Demo 的 344/356/720px 仅属示例。

同组统一基线、密度、图标与状态，不强制所有控件等宽。减少重复边框、白色胶囊和完整玻璃层，但保留必要的文字对比度保护。

动态选择用稳定标识；选中背景测量真实项目矩形，不写死 index × 总宽 / 3。处理增删、字体/字号变化和选中项移除。区分导航、单选、开关和动作语义；仅实际切换关联面板时用完整 tabs 模式。

弹层根据锚点与剩余空间定位；窄屏隐藏其他区域只是可选策略，采用时须同步隐藏语义/焦点，关闭后恢复。尺寸改变后同步材质几何；检查最短/最长标签、实际项目数量、缩放、断点和命中区域。

## 2. 提取边界

先找真实重复与差异。相同颜色/间距先复用 Tokens；多个调用点具有稳定的共同职责，或用户明确要求且有具体复用场景时才提取。优先已有库的配置、插槽或必要扩展，不为凑清单新增万能组件。

以下是候选职责，不是已导出的 API：

| 候选 | 负责的边界 |
|---|---|
| GlassScene / GlassSurface | 场景的来源、渲染与生命周期 / 表面的登记、几何和底板；布局由调用方决定 |
| FloatingBar / SegmentedControl | 操作分组与排布 / 选中值、事件、语义与指示位置 |
| IconButton / MorphPopover | 命中区与按钮状态 / 锚点、展开关闭、几何过渡与回焦 |
| SettingRow / MediaPicker | 标签和输入插槽 / 媒体选择、图片失败与空状态 |
| AppearancePolicy | 合并用户、系统偏好与真实渲染能力，不覆盖系统辅助功能需求 |

业务实体、照片路径、持久化键和文案留在调用方；避免全局 DOM ID 和共享意外状态。当前真正可用的渲染 API 是 globalThis.LiquidGlassOptics，接入时查 [接口](web-implementation.md#2-接口)。

只读建议给调用点依据、职责、接口方向与成本；实施提取要更新原调用点并验证多实例、动态内容、焦点、生命周期与框架检查。卸载清理观察器、事件、计时器和 GPU 资源。不要把候选名当现成组件导入，也不把原页面截图当新组件已验收。
