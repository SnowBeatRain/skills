# 间距与布局系统

## 间距基数

推荐 4px 或 8px 为基数：

| Token | 值 | Tailwind 类 | 用途 |
|-------|------|-------------|------|
| xs | 4px | `p-1` / `gap-1` | 图标与文字间距 |
| sm | 8px | `p-2` / `gap-2` | 紧凑元素内间距 |
| md | 12px | `p-3` / `gap-3` | 默认内间距 |
| lg | 16px | `p-4` / `gap-4` | 卡片内间距 |
| xl | 24px | `p-6` / `gap-6` | 区块间距 |
| 2xl | 32px | `p-8` / `gap-8` | 大区块间距 |
| 3xl | 48px | `p-12` / `gap-12` | 页面段落间距 |

## 圆角

| Token | 值 | 用途 |
|-------|------|------|
| sm | 4px | 小元素（badge、tag） |
| md | 8px | 按钮、输入框 |
| lg | 12px | 卡片、对话框 |
| xl | 16px | 大面板 |
| full | 9999px | 头像、圆形按钮 |

## 阴影层级

| 层级 | 效果 | 用途 |
|------|------|------|
| sm | 微阴影 | 卡片静止态 |
| md | 中阴影 | 卡片悬停态 |
| lg | 明显阴影 | 弹窗、下拉菜单 |
| xl | 强阴影 | 模态框 |

```css
:root {
  --shadow-sm: 0 1px 2px rgba(0, 0, 0, 0.05);
  --shadow-md: 0 4px 6px -1px rgba(0, 0, 0, 0.1);
  --shadow-lg: 0 10px 15px -3px rgba(0, 0, 0, 0.1);
  --shadow-xl: 0 20px 25px -5px rgba(0, 0, 0, 0.1);
}
```

## 响应式断点

| 名称 | 宽度 | 设备 |
|------|------|------|
| sm | ≥640px | 大手机横屏 |
| md | ≥768px | 平板竖屏 |
| lg | ≥1024px | 平板横屏 / 小笔记本 |
| xl | ≥1280px | 桌面 |
| 2xl | ≥1536px | 大桌面 |

## 容器

- 内容最大宽度：1200px ~ 1280px。
- 侧边栏宽度：240px ~ 280px。
- 主内容最小宽度：600px。
