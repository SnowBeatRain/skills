# 品牌视觉参考

> 灵感来源：yzfly/awesome-design-html、VoltAgent/awesome-design-md、bergside/awesome-design-skills。
> 以下为提炼后的视觉特征摘要，不包含原文或完整设计文件。

## Apple

- **关键词**：极简、留白、精致、高级感
- **色彩**：黑白为主，产品色点缀；深色模式用纯黑背景
- **字体**：SF Pro（系统），标题大字重 + 正文轻字重
- **布局**：大量留白，居中对称，大图/大字
- **动效**：平滑渐显、滚动驱动
- **适合**：产品页、品牌站、高级感落地页

## Linear

- **关键词**：科技、高效、渐变、暗色
- **色彩**：深色背景 + 紫蓝渐变 + 白色文字
- **字体**：Inter / 系统无衬线，标题加粗
- **布局**：密集信息、网格、紧凑但不拥挤
- **动效**：微交互丰富，光效、粒子
- **适合**：SaaS 工具、开发者产品、后台管理

## Stripe

- **关键词**：渐变、专业、动感、信任
- **色彩**：紫蓝渐变 + 精选配色，白色/浅灰背景
- **字体**：自定义 Stripe Sans（类似 Inter）
- **布局**：插画 + 文字组合，功能区块清晰
- **动效**：鼠标跟随、渐变流动
- **适合**：支付、金融、B2B 服务

## Notion

- **关键词**：温暖、友好、简洁、文艺
- **色彩**：浅色背景 + 黑色文字 + 棕色/米色点缀
- **字体**：自定义（衬线 + 无衬线混用）
- **布局**：卡片式、内容优先、插画点缀
- **动效**：轻柔、克制
- **适合**：笔记、知识管理、协作工具

## Airbnb

- **关键词**：温暖、包容、探索、图片驱动
- **色彩**：品牌粉（Rausch）+ 中性色 + 深色文字
- **字体**：Cereal（自定义无衬线）
- **布局**：大图轮播、卡片网格、搜索优先
- **动效**：微动画、展开收起
- **适合**：旅行、生活类、图片密集型

## Vercel

- **关键词**：极简、技术、黑白、精准
- **色彩**：纯黑/纯白 + 灰色梯度，极少量彩色
- **字体**：Geist（自研）
- **布局**：代码块 + 截图 + 居中文字
- **动效**：精准、技术感
- **适合**：开发工具、技术产品、个人品牌

## Claude

- **关键词**：温暖、智能、对话感
- **色彩**：陶土色/橙色系 + 奶油色背景
- **字体**：圆角无衬线
- **布局**：对话式、卡片、温和间距
- **适合**：AI 产品、对话界面、亲和力设计
