# 组件设计规范

## 按钮

| 变体 | 用途 | 视觉 |
|------|------|------|
| Primary | 主要操作（提交、确认） | 品牌色填充，白色文字 |
| Secondary | 次要操作（取消） | 浅色背景或描边 |
| Ghost | 辅助操作（筛选、排序） | 无背景，文字/图标 |
| Danger | 破坏性操作（删除） | 红色系 |

状态：Default → Hover → Active → Focus → Disabled → Loading。

## 卡片

| 变体 | 用途 |
|------|------|
| 默认 | 信息展示、列表项 |
| 紧凑 | 表格行、摘要 |
| 可交互 | 点击跳转、拖拽排序 |

卡片内间距推荐 16px ~ 24px。边框推荐 1px solid borderColor。

## 表单

### 输入框

- 高度：36px ~ 40px。
- 内间距：8px ~ 12px。
- 边框：1px，Focus 态 2px + 品牌色。
- 错误态：红色边框 + 错误文字。

### 标签与提示

- Label 在输入框上方，字号 sm，字重 medium。
- Placeholder 用中性色，与实际输入文字做区分。
- Helper text 在输入框下方，字号 xs。

## 导航

| 模式 | 适合 | 要点 |
|------|------|------|
| 顶部导航 | 官网、落地页 | Logo 左，操作右，中间链接 |
| 侧边导航 | 后台、工具 | 可折叠，图标 + 文字 |
| 底部导航 | 移动端 | 3~5 个主要入口 |

## 反馈

| 类型 | 用途 | 位置 |
|------|------|------|
| Toast | 操作结果反馈 | 页面右上角或底部 |
| Modal | 需要确认的操作 | 页面居中遮罩 |
| 内联提示 | 表单验证、上下文提示 | 紧邻相关元素 |
| Alert Banner | 全局通知 | 页面顶部 |

## 图标

- 推荐使用图标库：Lucide、Phosphor、Heroicons。
- 尺寸：16px（inline）、20px（按钮）、24px（导航）。
- 线条粗细与字体笔画粗细保持一致。
